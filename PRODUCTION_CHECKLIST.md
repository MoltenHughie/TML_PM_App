# TML — Video Production Checklist

## Overview
Standard workflow from idea → published video. Use this as a template for each video.

---

## Phase 1: Pre-Production

### Concept
- [ ] Video idea selected from backlog
- [ ] Audience defined (who is this for?)
- [ ] Promise clear (what do they get?)
- [ ] Outline drafted

### Script
- [ ] Full script written (or detailed bullet points for casual content)
- [ ] Hook reviewed (first 30 sec compelling?)
- [ ] Length estimated (target: 5-10 min for most content)
- [ ] CTA included (subscribe, next video tease, etc.)

### Planning
- [ ] B-roll shot list prepared
- [ ] Location(s) confirmed (gym, home office, etc.)
- [ ] Props/gear needed identified
- [ ] Shooting date scheduled

---

## Phase 2: Production

### Gear Check
- [ ] Camera charged + storage cleared
- [ ] Audio: mic tested, levels checked
- [ ] Lighting: natural light or ring light positioned
- [ ] Backup audio running (phone)

### Talking Head
- [ ] Wardrobe: simple, on-brand
- [ ] Environment clean (no distractions in frame)
- [ ] At least 2-3 full takes of script
- [ ] Pickup shots for any flubs

### B-roll
- [ ] All shots from list captured
- [ ] Variety: wide, medium, close-up
- [ ] Extra filler shots (hands typing, weights, etc.)

### On-Set Notes
- [ ] Note best takes (timestamps or markers)
- [ ] Note any script adjustments made live
- [ ] Backup all footage immediately

---

## Phase 3: Post-Production

### Rough Cut
- [ ] Import footage, organize by type
- [ ] Assemble rough cut (talking head + B-roll)
- [ ] Check pacing: is it dragging anywhere?
- [ ] Trim dead air, ums, long pauses

### Polish
- [ ] Color correction (subtle, consistent)
- [ ] Audio: normalize levels, reduce background noise
- [ ] Music: subtle background (not distracting)
- [ ] Graphics: lower thirds, text overlays where needed
- [ ] Intro/outro cards

### Review
- [ ] Watch full video at least once
- [ ] Check audio sync
- [ ] Verify no copyright issues (music, clips)
- [ ] Final runtime check

### Export
- [ ] Export at target quality (1080p or 4K)
- [ ] Verify file plays correctly
- [ ] Backup export file

---

## Phase 4: Publishing

### Metadata
- [ ] Title finalized (compelling, searchable)
- [ ] Description written (include keywords, links, timestamps)
- [ ] Tags added (10-15 relevant)
- [ ] Thumbnail: 3 options created, best selected

### Upload
- [ ] Upload to YouTube
- [ ] Verify processing complete
- [ ] Preview playback on platform

### Publish
- [ ] Schedule or publish immediately
- [ ] Cards and end screens added
- [ ] Playlist assignment (if applicable)

### Promotion
- [ ] Community post (if audience exists)
- [ ] Cross-post to socials (Instagram story, Twitter, etc.)
- [ ] Share in relevant communities (optional, tasteful)

---

## Phase 5: Post-Publish

### Analytics (check at 24h, 7d, 30d)
- [ ] Views
- [ ] Watch time / average view duration
- [ ] CTR (click-through rate)
- [ ] Comments / engagement

### Learnings
- [ ] What worked?
- [ ] What could improve?
- [ ] Update backlog / future scripts based on learnings

### Archive
- [ ] Move to "published" in VIDEO_IDEAS_BACKLOG.md
- [ ] Store raw footage (external drive) or delete if not needed
- [ ] Update project files if reusable assets created

---

## Quick Reference

### Ideal Video Length
- Standard: 5-10 min
- Deep Dive: 10-15 min
- Short/tip: 2-4 min

### Thumbnail Best Practices
- High contrast
- Minimal text (2-4 words max)
- Face visible (if relevant)
- Consistent branding / color scheme

### Title Formula Options
- "How I [verb] [thing]"
- "[Topic]: What I Learned"
- "The [Adjective] Guide to [Topic]"
- "[Number] [Things] About [Topic]"
